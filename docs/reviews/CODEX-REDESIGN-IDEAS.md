# 랜딩 재구성 아이디어

승인된 부가 서비스·네트워크·요금 시안과 시각적으로 겹치지 않도록 남은 구간의 역할을 나눴다. 문구와 수치는 기존 `useContent()` 데이터만 사용한다.

## Intro

흰 바탕에서 운송 여정 다음에 이어지는 안내문처럼 구성한다. 제목과 설명을 좌우로 나누고, 기존 운송 모드 문구만 한 줄 경로 표기로 묶어 시퀀스를 되풀이하지 않는다.

## Yard 리드인

야드 장면 위에는 실제 다음 동작을 예고하는 모노 라벨과 얇은 측정 눈금만 둔다. 새 경로·시간·물량 숫자는 만들지 않고, 기존 애니메이션의 컨테이너 적재를 설명하는 메시지만 쓴다.

## About + 인증

JSL 소개는 큰 2단 제목과 짧은 설명 뒤에 4개 강점을 번호 행으로 놓는다. 인증은 같은 흰 계열 바탕의 연속 등록부로 붙여 로고 대신 기존 인증명·등록 정보만 보여준다.

## Partners

남색 화면에서 운송사와 특송사 그룹을 두 개의 가로 장부 행으로 나눈다. 승인된 원본 로고만 그룹별로 놓고, 각 로고의 배경 패치가 필요한 경우 기존 설정을 그대로 따른다.

## Consulting

화주와 포워더를 흰 바탕의 좌우 열로 나누고, 각 열의 기존 항목을 번호와 얇은 규칙선으로 연결한다. 그룹 앵커를 보존하고 섹션당 주황 화살표 링크 하나만 둔다.

## Operations + Stats

남색 바탕을 유지하고 운영 상태와 기존 통계를 하나의 모노 데이터 시트로 정렬한다. 기존 상태·수치만 표시하며 지도나 새 차트를 더하지 않는다.

## FAQ

흰 바탕의 질문 목록을 번호와 하단 규칙선으로 정리하고, 답변은 현재 아코디언 동작으로 연다. 아이콘 배지나 접힌 카드 외곽선은 제거한다.

## CTA + Contact 래퍼

문의 전환 문구는 남색 구간에 짧게 두고, 바로 뒤 흰 폼 구간과 하나의 흐름으로 연결한다. CTA는 기존 `#contact`만 가리키며 새 문의 경로나 중복 폼을 만들지 않는다.

## 반대 의견 채택

모든 구간에 카운터를 붙이면 여정의 실제 정차와 보조 정보를 구분하기 어렵다. 여정 구간에만 카운터를 두고, About은 06, Consulting은 08을 표시하며 Partners와 인증은 경로 헤더만 남긴다.

진행 기록: 승인된 시각 규칙과 8개 구간 아이디어를 정리했고, `12698ef` 병합 후 About·Partners·Consulting을 연결했다. `npx eslint`는 통과했으며 `npx tsc --noEmit`은 기존 코드가 참조하는 이미지 asset 8개를 찾지 못해 14건 실패했다.
