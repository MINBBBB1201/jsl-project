## 모션·API·가림

- 일반 모션 en1440에서 대표수치200의 0→중간값→200을 관찰했다. 최종 실행에서 서로 다른47개 값이 기록됐다. 기존 CountUp 원본은 변경하지 않았다.
- 운영 요약은 합성503에서 섹션 전체가 접히고 B수치만 남았다. 합성 성공 응답에서는 별도 요약 패널을 유지했다. 실제 운영 데이터를 조회·검증한 결과가 아니다.
- 좁은 화면의 특정 scrollY10304에서 초기 B의180억원 글자(x277.4–366)가 테마 버튼(x326–374)과 겹쳤다. 오른쪽에48px의 텍스트 제외 영역을 두고 같은 위치에서 수치가x229.4–318로 옮겨져 겹침이 사라졌다. 초기 Range 기반 스윕의 음성 결과는 근거로 쓰지 않았다. 최종은 hydration 후 텍스트 요소 bounding box로48px 간격을 확인해 가림0건이었다.
- 첫 캡처 도구는 hydration 전 API호출 여부를 검사해 실패했다. 실제 summary응답을 기다리도록 고친 후 최종 검수했다. 앱 실패로 합산하지 않았다.
- 영상 녹화는 설치된FFmpeg1011과 현재 Playwright가 요구하는1013이 달라 시작하지 못했다. 추가 설치하지 않았고 영상 파일을 완료 증거로 제시하지 않는다. 모션 결과는 DOM실측으로 남겼다.
