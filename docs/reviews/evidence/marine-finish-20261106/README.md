# 선박·수면 실제 전후

2026-11-06. 로컬 실제 Next 앱의 PC·모바일 캡처다. 선박 이미지는 내장 OpenAI 이미지 생성 도구의 편집 결과이며 [생성 프롬프트·해시](asset-generation.json)를 함께 기록했다.

## 변경과 보존

선박의 낡은 도장·녹을 줄이고 선실·난간·갑판 디테일을 정돈했다. 수면은 보관된48샘플 wavelet 연구의12개 파형을 selected 실시간 셰이더로 가져왔다. 기존28개 전방향 교차파를 치환해 세포 모양의 반복 무늬를 줄였다. 새 사진·파형이 실제 장면에 반영됐는지 눈으로도 확인했다.

카메라·화물 메시·JSL 지붕 UV·진행률 시계·Kelvin·포말·항공 전환은 보존했다. 생성 모듈은 `sync-marine-water.mjs`로 upstream fragment만 교체하고 나머지 앱 코드가 동일한지 검사했다. 생성 파일 전체를 과거 초안으로 덮어쓰지 않았다.

프레임 캡처 후 셰이더 기록을 기대 해시와 대조했다. 이미지의 모든 프레임별 응답bytes를 당시에 수집한 것은 아니며, 별도 실제HTTP 대조와 변경되지 않은 경로·파일·화면을 근거로 연결했다. 이 한계는 `runtime-identity-check.json`에 남겼다. 검수 도구는 이후 실행부터 프레임별 같은 응답 해시와 wavelet12호출도 확인하도록 보완했다. 보완 후 전체24화면을 다시 실행했다고 쓰지 않는다.

## 한계

Cycles 전체 물·광원이나 위상을 그대로 재현한 결과는 아니다. 현재 구도를 보존했으며 사진/모델이 섞이는 기존58% dissolve와 역사적 WebGL fallback은 남아 있다. 이 후보의 최종 시각 선택·생성 도구 약관·상속 입력의 공개 사용 조건은 별도다. Safari·실기기·GPU 성능·연속 영상은 미검증이다. 도구의 오류0만으로 실사 품질을 주장하지 않는다.

`compare-1440.png`, `compare-390.png`는 실제 캡처를 같은 크기로 나란히 배치한 비교 이미지다. 원본 캡처와 기록은 `before*`, `after*`에 있다. 내부 OpenAI 검토는 다른 회사 모델의 리뷰가 아니다. main 병합·운영 배포는 하지 않았다.
