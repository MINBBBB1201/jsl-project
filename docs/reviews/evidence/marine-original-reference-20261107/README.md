# 작업 전 주황 컨테이너를 기준으로 한 재질 보정

사용자는13149a4의 모습도 어색하다고 지적하고 작업 전 컨테이너를 확인해 참고하도록 요청했다. 기존 자료를 먼저 대조한 뒤 수정했다.

## 확인한 기준

- 실제 앱 기준은 해상 변경 전09eeb2c의52% 캡처다. 큰 골판, 약간 닳은 주황 도장, 중앙의 작은 JSL이 보인다. 이 근접 장면은 현재도 유지된다.
- 원본은 초안c9763d5의 `roof-quality.avif`다. 현재 파일과 바이트가 같고 크기는69,357 bytes, SHA-256은 `af120258fe0b376f8bdd840e9830b7949fcb8e28470676afc0f0e522214cc038`이다.
- 직전 사진 편집은 글자가 커지고 골판이 약해져 원래 재질과 달라졌다. 이 결과를 최종 승인으로 계산하지 않는다.

## 수정한 범위

원본 지붕 재질을 기존 사진 material의 한 칸에 직접 등록한다. 원본 이미지 전체와 native 지붕의 실제 UV 방향을 사용하며 글자를 새로 쓰거나 확대하지 않는다. 공유 texture의 crop·repeat·offset을 바꾸지 않는다. 추가 상자나 별도 decal geometry는 없다.

선박 사진은7b5ade7의 밝은 중립색 plate로 되돌렸다. 이전의 큰 JSL 사진 편집은 사용하지 않는다. 낡은 선박과 주황 화물 두 개가 있는 옛 사진 전체를 복원한 것은 아니다. 카메라·수면·운송 동선·native 근접 장면과 기존 사진 전환 범위는 유지한다.
