# 테마 설정 버튼과 운송 시퀀스 AIR 탭 겹침 수정 (#49)

- 구현: Claude Opus 5.5 (`claude-opus-5-5`, Anthropic) 클라우드 세션. 독립 검토는 Codex 담당이며 이 기록은 자체 검사입니다.
- 소스: `frontend/src/app/landing/components/landing-theme-customizer.tsx`만 변경(`95f1bff`, `c8ee0ce`). PR #49 브랜치에는 `0f85148`(PR #29)을 merge(`e08b709`)로 먼저 가져왔습니다.
- 통합 검증 tree: PR29 `0f85148` + PR49 head + PR52 `3309630` → `526c52c7818908b602cd42747bfccea4589e8761`. 이전 통합 `974a7dc`와의 차이는 위 파일 한 개(+71/−1).

## 문제
390·768 폭에서 오른쪽 아래 테마 버튼(`fixed bottom-6 right-4`, 48px)이 운송 시퀀스 고정 구간 내내 모드 탭 `04 · AIR`(`#jsl-marine-native .mm-mode-nav`, 하단 3.8%, 좌우 5%)를 덮어 AIR 탭을 누를 수 없었습니다. 1440에서는 탭 오른쪽 끝(1368px)이 버튼(1376px~)보다 왼쪽이라 겹치지 않습니다.

## 방식과 트레이드오프
- 스크롤(양방향)·리사이즈마다 한 프레임에 한 번, 스크롤이 멈춘 뒤 450ms에 한 번 더 비킬 대상의 실제 위치를 재고, 버튼 기본 자리와 겹칠 때만 `translateY`로 대상 윗변 12px 위로 올립니다. 겹치지 않으면 원래 자리입니다.
- 비킬 대상: 운송 시퀀스 모드 탭(보이는 동안만; 엔진이 `visibility:hidden`으로 숨기면 비키지 않음), 히어로 화물조회 칸(320×640 첫 화면에서 겹침).
- 버튼은 숨기거나 끄지 않아 테마 설정은 계속 열 수 있습니다. 엔진·탭·장면·주황 테마 파일은 바꾸지 않았고 엔진 클래스는 읽기만 합니다.
- 동작 줄이기에서는 버튼 이동 전환을 끕니다(`motion-reduce:transition-none`).
- 트레이드오프: 고정 구간 동안 버튼이 390에서 49px, 768에서 70px 위에 떠 있습니다. 엔진 마크업 클래스를 읽으므로 엔진이 클래스를 바꾸면 목록을 갱신해야 합니다. 스크롤 중 지나가는 본문 링크·FAQ·입력칸 위에 잠깐 얹히는 것은 떠 있는 버튼의 일반 동작이라 대상에 넣지 않았습니다(아래 표의 나머지 수치).
- 함께 고친 것: 테마 패널은 `SheetTrigger` 없이 열려 닫히면 포커스가 사라졌습니다. 닫힐 때 여는 버튼으로 포커스를 돌려줍니다.

## 측정 (운영 빌드 `next start`, headless Chromium)
버튼을 `pointer-events:none`으로 잠시 바꾸고 아래 요소를 5점 샘플링(매번 원래 값 복구 확인). 페이지 전체를 300px 간격으로 내려가고 600px 간격으로 올라옴.

| 조건 | 고정 구간 AIR 가림 횟수 (전 `974a7dc` → 후 `526c52c`) |
|---|---|
| ko 390 내려가기 / 올라오기 | 39 → 1 / 19 → 0 |
| vi 390 내려가기 / 올라오기 | 40 → 0 / 20 → 1 |
| en 768 내려가기 / 올라오기 | 48 → 1 / 24 → 1 |
| en 1440 | 0 → 0 |

남은 1회는 고정이 풀리거나 다시 고정되는 순간의 측정(70ms)이 버튼 이동 전환 중에 걸린 것입니다. 같은 위치에서 400ms 뒤에는 겹침 없음을 따로 확인했습니다.

- 고정 상태: 버튼 아래 조작부 0, AIR 탭 실제 클릭됨(전에는 클릭이 버튼에 막힘).
- 고정 상태 리사이즈 390→768→1440→390: 매번 겹침 0, 버튼 위치 갱신.
- vi 320×640 첫 화면: 화물조회 버튼 가림 1 → 0.
- 테마 패널: 키보드 Enter로 열기·Esc로 닫기, 닫힌 뒤 포커스 버튼 복귀(전: 복귀 안 됨).
- 동작 줄이기(ko 390, en 768): 운송 시퀀스 대신 정적 화면이라 모드 탭 없음, 페이지 오류 0.
