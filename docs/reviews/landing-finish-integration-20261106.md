문의 에이전트는 #25 `f6c48b2bd90030cd8923e3235e5fffabc40bf480`의 계약·테스트를 외부 폴더에 준비했고, 회사소개 에이전트는 매체 연결과 모바일 히어로 변경을 별도 패치로 준비했다. 부모 Codex만 공통 작업본에 적용하고 빌드·서버·최종 검수를 실행했다. 에이전트 검토는 같은 OpenAI 계열이며 타사 독립 리뷰가 아니다.

## 실제 변경

- 회사소개: 큰 현장 매체와 `Every move. One JSL.` 구도에 새로 생성한 도크 이미지를 연결했다. PC/모바일 크롭을 분리하고, 이미지 아래 네 언어로 AI 콘셉트이며 실제 JSL 시설 사진이 아님을 표시했다. 외부 Viamaster 검토 이미지를 운영 매체로 복사하지 않았다. 새 PNG의 생성 기록은 `frontend/public/images/company/SOURCES.md`에 있다.
- 문의: #25의 고지 조회, 필수/선택 항목, 명시적 동의, 접수번호, 응답 유실 재시도, 고지 변경 후 재동의를 통합했다. backend의 지속 저장·고유 인덱스·알림 처리를 포함한다. 기존 일반 JSON 10KB/404와 문의 전용 JSON 32KB 오류 계약을 유지한다. 정책 예시는 모두 비활성 상태다.
- 폼 표시: 랜딩의 `.shadow-xs` 초기화가 체크박스의 배경·테두리를 지우던 충돌을 문의 안에서만 보정했다. 선택됨과 키보드 포커스가 보인다.
- 모바일 히어로: 600px 이하 트랙을 190svh에서 145svh로 줄이고, 글자 퇴장 시작을 18%에서 48%로 늦췄다. 지구본 이동 궤적·폰트·메뉴는 유지했다. 이동하는 전환막의 앞부분을 부드럽게 처리해 직선으로 잘리던 경계를 완화했다. 분수 viewport 폭에서 GSAP 조건이 비는 경계도 없앴다.
- 모바일 구름: 해상 단계에서는 구름이 미리 화면 양옆으로 들어오지 않게 했다. 좁은 화면에서 두 구름 이미지가 겹치던 것을 한 장으로 줄였다. 생성 엔진 파일, 선박·물·비행기 자산은 수정하지 않았다. 현재 구름 자체의 해상도 문제를 해결한 작업은 아니다.

문의 브라우저 검사의 첫 버전은 SSR의 준비 중 문구를 hydration 완료로 잘못 판단해 조기 실패했다. 실패 캡처용 DOM 삽입으로 React 418도 발생했다. 다음 버전은 Playwright `response.finished()` 대기에서 멈춰 종료했다. 첫 고지 GET 응답 확인, 단계별 제한시간, 초기 실패 시 DOM 무변경으로 도구를 수정했다. 최종 네 조합은 실제 앱 오류를 숨기지 않은 상태로 모두 통과했다. 이 두 실패를 앱의 동작 실패나 통과 결과에 합산하지 않았다.

브라우저 검수 스크립트는 `tools/landing-review/contact-form-browser.cjs`다. 기존 Playwright 경로를 `JSL_PLAYWRIGHT_MODULE`, 브라우저 실행 파일을 `JSL_CHROMIUM_PATH`, 로컬 주소를 `JSL_REVIEW_URL`로 지정한다. 경로만 환경변수화한 저장본의 구문 검사도 통과했다. 합성 API 외의 API와 외부 네트워크는 차단한다.
