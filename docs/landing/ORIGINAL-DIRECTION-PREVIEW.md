## 비교 초안

두 방향 모두 **운송수단 → 화물 과정 → 아시아 운영 거점** 세 장면이다. 기존 실제 화면 캡처를 확인하고 콘텐츠 위계를 기준으로 만들었다. 원본 사이트 캡처나 실제 3D 렌더가 아닌, 이미지 생성 도구로 만든 정지 시안이다.

| 방향 | 표현 | 장점 | 실제 제작 시 필요한 것 |
|---|---|---|---|
| 실제 현장 | 항만·야간 창고의 사진에 가까운 장면 | 현장감, 산업적 신뢰감 | 실제 JSL 서비스에 맞는 매체, 동일 컨테이너의 도장/마모 통일 |
| 정밀 미니어처 | 밝은 물류 단지·창고 단면·지역 모형 | 기존 3D 모션과 연결, 자체 모델로 일관된 세계 구성 | 정확한 장비 모델, 실제 축척/접촉, 지역 데이터 |

**제안:** UC를 기준으로 한 움직임을 이어갈 첫 검증 후보는 정밀 미니어처다. 아직 선택·승인된 방향은 아니다. 실사와 미니어처를 매 슬라이드마다 번갈아 섞지 않고, 선택한 표현을 같은 컨테이너와 조명/재질 규칙으로 이어가는 것을 제안한다.

화면 위계는 원래 참고한 장면의 기능을 유지한다. 운송수단은 전체 매체+5모드 선택, 화물 과정은 큰 제목+단계별 장면+본문, 네트워크는 지도+5거점 선택이다. 레퍼런스의 카드/폰트/장식만 조각내 혼합한 화면은 만들지 않았다.

### 통합 규칙 — 제안, 구현되지 않음

1. 동일한 주황 JSL 컨테이너 한 모델을 주인공으로 사용한다. 비율·리브·로고·마모가 장면마다 바뀌지 않는다.
2. 흰 공간 → 남색 창고 → 어두운 지도 대비를 유지하고, 공통 UI·선택 상태에 남색/주황을 쓴다.
3. 기존 스크롤/카메라 흐름은 기준으로 보존한다. 이동 방향·멈춤·다음 장면 진입을 먼저 측정하고 새 자산에 연결한다.
4. 컨테이너를 계속 따라가는 장면은 같은 3D 좌표계에서 제작한다. 사진 교차 페이드를 회전/운반으로 설명하지 않는다.
5. 한 장면 안에서 산업 시설의 형태와 동작을 먼저 검증한다. 같은 디자인 규칙으로 이어갈 수 있을 때 다음 장면으로 확장한다.

## 확인한 한계

- **정지 시안:** 실제 스크롤 애니메이션·차량 이동·집게 접촉·트레일러 적재를 구현하거나 통과한 결과가 아니다.
- **지도:** 생성된 해안선, Weihai 등 위치와 연결선은 미검증이다. 실제 구현은 공개 지리 데이터와 확인한 거점 좌표로 다시 만든다. 임의 경로를 실제 운송 노선으로 표시하지 않는다.
- **브랜드:** 시안의 선박/기관차 등에 붙은 JSL 표시는 최종 자산에서 주인공 컨테이너 중심으로 정리한다. 현장 장면을 JSL 소유 시설로 주장하지 않는다.
- **컨테이너:** 실제 현장 방향의 마지막 장면은 마모가 심해 동일 화물의 연속성이 약하다. 최종 제작에서 같은 모델/텍스처로 통일해야 한다.
- **폰트/모바일:** 이미지에 표현된 글꼴은 확정된 폰트 구현이 아니다. 모바일 검수는 비교 시안 표시와 전환을 확인한 것이며, 모바일 랜딩 완성 검수가 아니다.
