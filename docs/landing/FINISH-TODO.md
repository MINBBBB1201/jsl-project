## 마지막 순서: 시각 자산과 내부 테마

다음 두 항목은 2026-11-06 사용자 피드백으로 추가했다. 현재 화면을 즉시 바꾸지 않고 후속 디자인 작업으로 다룬다.

- [ ] 상담 CTA 정리: `Logistics consultation`, `5+1 full line-up` 등 표현과 초록·파랑·보라 표시등을 검토한다. 임의의 실시간 상태처럼 보이는 장식을 줄이고, 실제 서비스 내용이 자연스럽게 읽히도록 기존 주황 테마 안에서 구성한다. 문구의 사실성과 네 언어 의미를 보존하며 PC·모바일 전후 캡처로 선택한다.
- [ ] 실적·물동량 구간 차별화: 주황색으로만 바꾼 상단 발광 그라데이션, 검은 바탕과 동일한 사각 지표 배열을 그대로 답습하지 않는다. 기존 매출·거점·고객·물동량 수치와 링크는 유지하되 첫 지구본 장면과 이어지는 JSL 고유 구도를 비교안으로 제시한다. 색상 조정만으로 완료 처리하지 않는다.

1. [ ] 낡지 않은 선박 외형과 자연스러운 구도. 화물 연결·정지·출항 흐름 보존.
2. [ ] 보관된 물 렌더를 같은 카메라로 비교해 품질이 가장 좋은 안 선택.
3. [ ] 비행기·구름 고해상도 재제작. 사용자 지정 Gemini 연결 방식부터 확인. 이번 모바일 중첩 보정은 이미지 재제작 완료가 아님.
4. [ ] 위 자산의 PC·모바일 같은 구도 전후 캡처와 이동 중 프레임 검수.
5. [ ] 내부 대시보드 테마를 주황색으로 통일. 현재 랜딩 테마 작업과 분리하며 마지막에 진행.
