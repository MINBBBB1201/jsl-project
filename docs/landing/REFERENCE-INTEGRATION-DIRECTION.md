작성: 2026-10-01. 이번 작업은 방향 제안 및 개발·검수 도구 준비다. 실제 랜딩, 히어로, 14번 장면, 메시지와 자산은 수정하지 않는다.

## 1. 기준과 현재 상태

- 사용자가 받아들인 전체 슬라이드 초안: `C:/Users/mimin/.codex/visualizations/2026/09/15/01a0a4cd-b26a-7f80-a32c-befc97923b12/jsl-full-slide-transplant-draft.html`.
- 한 장면에는 한 레퍼런스의 전체 구성을 적용한다. 여러 레퍼런스의 카드·폰트·장비를 한 화면 안에 섞지 않는다.
- United Carriers가 현재 사이트의 애니메이션 흐름을 이루는 기준이다. 기존 히어로와 유지 장면을 보존한다.

## 3. 통일할 범위

### 공통 외곽

- 상단 메뉴, 언어 선택, 진행 표시, 문의 버튼은 JSL 한 세트로 공유한다.
- 레퍼런스의 여러 헤더를 매 장면마다 함께 노출하지 않는다.
- 콘텐츠 영역 안의 고유 레이아웃과 여백은 유지한다. 공통 카드 그리드나 새 장식 패널로 바꾸지 않는다.

### 색과 재질

- 흰 장면과 검은 장면의 대비를 유지한다. 전체를 남색 배경으로 덮지 않는다.
- JSL 남색/주황은 공통 UI, 활성 상태, 동일 화물 표시에 먼저 적용한다.
- 레퍼런스 본문 전체의 주색·재질 교체는 비교 시안에서 판단한다. 색을 통일한다는 이유로 원본의 대비와 위계를 지우지 않는다.
- 실제 영상·사진은 밝기, 검정 레벨, 채도를 비교한다. 자산의 질감·장비 외형을 CSS 사각형으로 대체하지 않는다.

### 타이포그래피

- 기존 히어로 폰트는 별도 지시 전까지 보존한다.
- 교체 슬라이드는 승인된 원본의 글자 크기 관계와 줄바꿈 역할을 유지한다.
- 추후 폰트 교체 후보는 Noto Sans 계열의 ko/en/zh/vi 실제 글리프를 확인한 뒤 비교한다. 원본 폰트·Space Mono를 새로 도입하지 않는다.
- 번역문이 길면 해당 텍스트 영역 안에서 줄바꿈·본문 크기를 조정한다. 전 화면의 구성 자체를 재설계하지 않는다.

### 모션

- 각 레퍼런스 내부의 움직임과 카메라 방향을 유지한다. 장면 사이의 진입/퇴장 속도, 멈춤 구간, 스크롤 거리만 조율한다.
- 정보가 읽히는 멈춤 구간과 이동 구간을 구별한다. 모든 장면에 동일한 페이드·패럴랙스를 반복 적용하지 않는다.
- 장비 동작은 집게/컨테이너/트레일러를 같은 좌표계와 비율로 다룬다. 사진 두 장 교차 페이드를 회전으로 설명하지 않는다.
- 정방향, 역방향, 리사이즈, 폰트·영상 로딩 후 스크롤 위치를 확인한다. 감소된 모션 설정도 고려한다.

## 4. 다음 구현의 검수 순서

1. 변경할 장면과 파일, 보존할 부분, 정확한 원본 구간을 먼저 보고한다.
2. 먼저 인접한 Emons → Freezpak 두 장면으로 연결 시안을 만든다. 현재 제안 단계에서는 원본 파일을 수정하지 않는다.
3. 같은 화면 크기 1440×900으로 각 장면의 진입·중간·퇴장 화면과 이어지는 짧은 영상을 만든다. 모바일 비교 기준은 390×844다.
4. 실제 장비를 움직이는 장면은 시작·들기·적재·출발의 네 화면을 추가로 비교한다. 들어 올리는 동안 집게가 컨테이너 상단에 닿아야 하며, 적재가 끝나면 컨테이너 바닥이 트레일러 적재면에 닿아야 한다. 이전 흰 컨테이너가 남거나, 떠 보이거나, 비율이 갑자기 바뀌면 실패다.
5. 정지 프레임과 사이 구간이 통과한 뒤 스크롤에 연결한다. 시작점·끝점뿐 아니라 접촉을 전환하는 중간 프레임까지 확인한다.
6. 사용자에게 이 연결을 보여준 뒤 같은 방식으로 다음 연결을 확장한다. 동작은 계속 검증하되 사용자가 이미 승인한 범위를 반복 확인하지 않는다.

## 5. 토큰과 시간 관리

- 레퍼런스별 조사 전체를 매번 반복하지 않는다. 선택한 구간만 라이브 브라우저에서 확인하고 캡처/측정값을 재사용한다.
- 구간마다 원본 URL, 화면 크기, 시작/중간/끝 위치, 자산, 관찰/추론 여부를 남긴다.
- 새 범위를 시작할 때 체크포인트를 저장한다. 승인된 영역을 의도치 않게 수정했는지 파일 해시로 확인한다. 해시 차이는 보고만 하며 자동 롤백하지 않는다.
- 도구 설치는 검증 수단이다. 좋은 모션과 자산 제작을 자동으로 보장하지 않는다.
