# 쿠키·외부 전송·운영 정책 확인 — 2026-10-24

문의 재시도 복구를 구현했고, 현재 소스의 저장 항목과 정책 불일치를 조사했다. 실제 배포의 네트워크 기록이나 법적 적합성을 확인한 결과는 아니다.

## 기준과 보존 범위

- 문의 기능: PR #25의 `aca494e2cb6d75a8c99aed35eb68dc24cf8e5fe1`과 이슈 #39 변경분.
- 랜딩 본체: PR #29의 `c28108ad23cecac0f9f3fa94e9018d33b4773f63`을 읽기 전용으로 확인했다.
- 위 두 브랜치가 통합된 화면은 검사하지 않았다. 랜딩·푸터·내부 메뉴·라우팅·백엔드·법적 문구는 이 작업에서 수정하지 않았다.
- `frontend/src`의 TS·TSX·CSS, 앱 구성과 패키지 선언을 검색했다. 환경 변수의 실제 값, 고객 자료와 운영 DB는 읽지 않았다.

## 확인한 브라우저 저장 항목

| 항목 | 코드 근거와 값 | 범위와 수명 | 확인 한계 |
| --- | --- | --- | --- |
| `nextjs-ui-theme` | `app/layout.tsx`, `components/theme-provider.tsx`; light/dark/system 선택 | localStorage, 코드상 만료 없음 | 실제 배포에서 생성·삭제되는 시점은 미검사 |
| `jsl_token` | `lib/auth.ts`; 로그인 토큰 | cookie, Path=/, 12시간, SameSite=Lax, HTTPS에서 Secure | JavaScript가 읽는 쿠키다. 백엔드의 별도 인증과 운영 구성을 함께 확인해야 한다 |
| `sidebar_state` | `components/ui/sidebar.tsx`; 사이드바 열림 상태 | cookie, Path=/, 7일 | 대시보드 사이드바의 변경 때 기록한다. 공개 랜딩의 자동 기록으로 단정하지 않는다 |
| `NEXT_LOCALE` | `i18n/routing.ts`와 설치된 next-intl의 `routing/config.js`, `middleware/syncCookie.js` | 조건부 언어 cookie; 기본 SameSite=Lax, 명시 maxAge 없음 | `localeDetection: false`만으로 쿠키가 꺼지지는 않는다. 실제 Set-Cookie·언어 전환은 미검사 |
| `jsl.contact.retry.v1` | 이슈 #39의 `lib/contact-inquiry-retry.ts` | sessionStorage; 미확정 문의 1건, 논리적 유효기간 30분 | 다음 접근 때 만료 항목을 폐기한다. 30분에 백그라운드 삭제하는 타이머는 없다 |

재시도 항목은 버전, 무작위 요청 키, 그 키를 섞어 계산한 SHA-256 비교값, 만료 시각만 저장한다. 이름·이메일·문의 원문·동의값은 저장하지 않는다. 비교값을 익명 정보나 암호문으로 표현하지 않는다. 같은 origin의 스크립트는 이 메타데이터를 읽을 수 있다.

sessionStorage는 새로고침을 넘어서 유지되지만 탭을 닫으면 통상 종료된다. opener에서 복제된 탭의 초기 저장소가 복사될 수 있고, 브라우저 정책이 접근을 막을 수도 있다. [MDN의 sessionStorage 설명](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage)을 기준으로 이 한계를 남긴다.

## 정책 문구와 구현이 맞지 않는 부분

`config/legal-content.ts`는 스스로 검토 전 초안이라고 표시한다. 한국어 개인정보 초안은 회사명을 필수 수집 항목으로 쓰고 AI 챗봇 상담을 수집 경로로 기재한다. PR #25 문의 폼은 회사명·제목을 선택 항목으로 처리한다. PR #29의 랜딩 조합에는 공개 챗봇이 없다. 해당 초안의 3년 보유·대표자 책임자·시행일도 승인된 운영 입력으로 사용하지 않는다.

이 작업에서는 법적 문구를 고치거나 확정하지 않았다. 운영자 확인 후 실제 수집 경로·필드·처리업체·보유 및 삭제 방식에 맞춰 네 언어 문안을 검토해야 한다.

| 필요한 입력 | 현재 확인한 상태 | 코드나 운영의 다음 행동 |
| --- | --- | --- |
| 문의 목적·필수/선택 항목 | 코드의 허용 필드와 필수 필드는 정해져 있다 | 회사가 실제 필요한 항목을 승인한 고지에 맞춘다 |
